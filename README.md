#  Journey Project 
An Arabic personal growth and journey tracker designed to help users track their daily habits and achieve their goals.
## Live Demo 
You can try the live website here.
[Live Demo Link](https://r80545621-bot/github.io/Journey-Project/) 
## Features 
* **Modern UI/UX:** Dark mode theme with a glowing moon aesthetic.
* **Responsive Design:** Works perfectly on mobile and desktop.
* **RTL Support:** Fully optimized for the Arabic language (Right-To-Left).
**Interactive:** Smooth transitions and interactive elements using Vanilla JS.
## Tech Stack
* HTML
* CSS
* JavaScript (Vanilla)
